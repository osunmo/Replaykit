# ReplayKit R1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox syntax for tracking.

**Goal:** Deliver the first honest executable incident-to-judge workflow.
**Architecture:** Visible input contracts feed a pure planner. Candidate tests execute in containers against isolated checkout/Postgres services; a trusted judge gathers independent evidence and evaluates a fixed variant matrix.
**Tech Stack:** Node 22+, pnpm 10, TypeScript ESM, Zod, Fastify, pg, Vitest, Docker, OpenTelemetry.
**Spec:** ../specs/2026-10-16-r1-design.md and ../../../AGENTS.md.

## Global Constraints

- No candidate code execution on the developer host.
- No hidden truth access by the planner or candidate.
- No sleep-based correctness, no invented metrics, no hardcoded successful checks.
- VERIFIED requires matching domain failure, both valid fixes, rejected decoy, and 10/10 fresh buggy runs.
- All operational outputs are local synthetic data; no production writes.

## Review Focus

1. Poisoned or oversized incident input must not become shell arguments or code.
2. Infrastructure failures must not count as reproductions or abstentions.
3. Matching exception names on a different code path must fail identity checks.
4. A candidate that passes without exercising the scenario must fail trusted state checks.
5. Cleanup after errors must remove only resources owned by this run.
